# Connoisr User Stories: Strategic Requirements

## 🍽️ Persona: The Diner (Guest Experience)
- **Zero-Auth Access:** As a diner, I want to scan a QR code and reach the menu in under 3 seconds without creating an account or downloading an app, so I can start my dining experience immediately.
- **Identity Management:** As a member of a group table, I want to enter a nickname or join as a randomized guest so that my orders are identified by the kitchen and server (e.g., "Crispy Brioche") without compromising my privacy.
- **Visual Browsing:** As a hungry patron, I want to see high-quality images and clear dietary tags (e.g., GF, Vegetarian) on menu items so I can make quick, informed decisions.
- **Real-Time Totaling:** As a budget-conscious diner, I want a persistent "Smart Pill" floating cart that tracks my real-time total as I add items, so I am never surprised by the final bill.
- **Offline Resilience:** As a diner in a location with poor Wi-Fi, I want the app to handle connection drops gracefully using PWA caching so my order progress isn't lost.

## 👨‍🍳 Persona: The Kitchen Staff (Back-of-House)
- **Visual Prioritization:** As a line cook, I want the KDS to use functional color theory (e.g., Emerald for new, Burnt Sienna for overdue) so I can prioritize prep tasks without reading fine print.
- **Sync Accuracy:** As a chef, I want real-time state updates across all KDS screens so that when an order is updated at the table, it reflects instantly on my board.
- **Status Communication:** As a kitchen manager, I want to signal "Menu Ready" status to the front-end so diners know when the kitchen is actively accepting orders.

## 🍷 Persona: The Server (Hospitality Efficiency)
- **Precision Service:** As a server, I want the app to tag each order with a specific table ID and diner name so I can deliver the correct plate to the correct person without asking "Who had the risotto?".
- **Focus Shift:** As a professional server, I want the PWA to handle the routine "order taking" so I can focus on high-value hospitality tasks like wine pairings and clearing tables.

## 📈 Persona: The Owner (Business Logic)
- **Brand Consistency:** As a luxury restaurant owner, I want the digital interface to use "Midnight Slate" or "Alabaster" palettes to match the physical stone and gold materials of my venue.
- **Increased Yield:** As a business owner, I want a frictionless <3-tap ordering path to increase table turnover and average check size through ease of use.
